How this is organised

Component categories are canonical and device-agnostic. Hypodermic tubing shows up under both reusable instruments and needles, but it has exactly one page — device pages reference it rather than copying it. 4 categories are currently shared this way.

Every drawing here is generated in-repo from the same numbers the category is about, so a cross-section cannot quietly disagree with a spec table. None of it is traced from anyone's catalog art. The rules are written down in DRAWING_STANDARD.md.

What is here today

  • 5 device types, one signed off and four in draft taxonomy pending review.
  • 20 component categories with a line drawing and a plain description of what each does.
  • 13 categories mapped across the catheter shaft, grouped by where they sit on the device.

What is coming

  • Category pages with dimensional filters, and a cross-section glyph on each filter so OD, ID and wall stop being confused.
  • About pages where construction is not obvious from a spec table — the catheter wall stack first.
  • Two ways to act per component: request a quote from a matched custom supplier, or go straight to a distributor to order stock. Neither ships until the relationships behind them are real.
