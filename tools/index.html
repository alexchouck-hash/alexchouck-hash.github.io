Tools

We build the tooling. Some of it is free.

Five free tools on public records, running now, and the software that runs inside the paid lines. The service-line demonstrations use synthetic data against a fictional device — never a client's file.

Five free tools are live. They run on public records in your browser, with no account and no charge, and each carries a badge in its own chrome saying what it reads. The Opportunity Analyzer runs too, but scores against a rubric whose wording is still a marked draft — it says so on every view.

The service-line tools below are not live. Each capture is a preview of a settled interface rather than a recording of finished software, and each carries a badge saying which. They are here because showing the shape of the work is more useful than describing it.

Inside the service lines

These run inside paid engagements. They are shown for one reason: "AI-assisted with a named human reviewer" is a claim, and a claim about how software behaves should be watchable. Every one of these captures ends on the same beat — the export stays blocked until a person has signed for it.

What must stay true of this tool, or the demonstration comes down:

  • A requirement with no evidence is scored CANNOT ASSESS, never guessed.
  • Every finding cites its evidence to document, section and line.
  • Safety-critical items are never auto-dispositioned by a bulk action.
  • Export is blocked until a named reviewer dispositions every finding.

It runs inside Remediate 10x.

What must stay true of this tool, or the demonstration comes down:

  • Harms come from a curated, versioned library — never free generation.
  • Severity tied to patient harm is never auto-scored; a person sets it.
  • A red-flagged item is never dispositioned by a bulk action.
  • Nothing exports until every row carries a named disposition.

It runs inside Develop 10x.

What must stay true of this tool, or the demonstration comes down:

  • The loop does not close without a named reviewer.
  • Planned values are labelled as planned; nothing is presented as measured.
  • No protocol and no report leaves the loop without a name on the record.

It runs inside V&V 10x.

What must stay true of this tool, or the demonstration comes down:

  • Nothing sends without a named human approval on the record.
  • The founder-time figures are a modelled design target, never presented as measured.

It runs inside Pulse.
