Tools

The tools, running.

Each of these runs inside a service line today. Every demonstration below uses synthetic data against a fictional device — never a client's file, and never a real device.

We build the tooling we use. This page shows it working rather than describing it, because a claim about a tool is worth less than thirty seconds of watching it refuse to do the wrong thing.

Every capture here runs on synthetic data against a fictional device. A client's file is never a demo — that would be the exact behaviour the data page argues against.

What must stay true of this tool, or the demonstration comes down:

  • A requirement with no evidence is scored CANNOT ASSESS, never guessed.
  • Every finding cites its evidence to document, section and line.
  • Safety-critical items are never auto-dispositioned by a bulk action.
  • Export is blocked until a named reviewer dispositions every finding.

It runs inside Remediate 10x.

What must stay true of this tool, or the demonstration comes down:

  • Harms come from a curated, versioned library — never free generation.
  • Severity tied to patient harm is never auto-scored; a person sets it.
  • A red-flagged item is never dispositioned by a bulk action.
  • Nothing exports until every row carries a named disposition.

It runs inside Develop 10x.

What must stay true of this tool, or the demonstration comes down:

  • The loop does not close without a named reviewer.
  • Planned values are labelled as planned; nothing is presented as measured.
  • No protocol and no report leaves the loop without a name on the record.

It runs inside V&V 10x.

What must stay true of this tool, or the demonstration comes down:

  • Nothing sends without a named human approval on the record.
  • The founder-time figures are a modelled design target, never presented as measured.

It runs inside Pulse.

What must stay true of this tool, or the demonstration comes down:

  • Every edge cites a public 510(k) record that can be opened.
  • It reads public data only — no account, no private data.

What must stay true of this tool, or the demonstration comes down:

  • Every number carries the query that produced it.
  • It reports a distribution from the public record, never a prediction.
  • It reads public data only — no account required.
